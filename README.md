# .github

Default community health files for the Kubereum organization.

This repository holds the org-wide profile, security policy, and any shared GitHub configuration that applies across all kubereum/* repositories.

- `profile/README.md` renders on https://github.com/kubereum
- `SECURITY.md` is the default security policy for repos that do not define their own

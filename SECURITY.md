# Security Policy

## Reporting a Vulnerability

If you find a security issue in any Kubereum repository or service, email security@kubereum.com.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Affected versions or endpoints
- Your contact information for follow-up

## Response Timeline

- Acknowledgement within 72 hours
- Initial assessment within 7 days
- Fix or mitigation timeline shared after the assessment

## Scope

In scope:
- Production code in any kubereum/* repository
- API endpoints under *.kubereum.com
- Customer data handling and authentication

Out of scope:
- Third-party services we depend on (report to those vendors directly)
- Spam, phishing, or social engineering attempts
- Issues that have already been disclosed publicly

## Disclosure

We follow responsible disclosure. We will not pursue legal action against researchers who:
- Avoid privacy violations and service degradation
- Do not access more data than necessary
- Give us reasonable time to fix the issue before public disclosure

Thank you for helping keep our users safe.
